## Nome

Fila Mack.

## Problema

O setor acadêmico precisa controlar a fila de atendimento.

## Objetivo

Construir um sistema para emitir e chamar senhas.

## Usuários

- Aluno.
- Atendente.

## Escopo

- emissão de senhas;
- chamada de senhas;
- finalização de atendimento;
- visualização da fila.

## Fora do escopo

- autenticação de usuários;
- persistência em banco de dados ou em arquivos;
- senhas prioritárias;
- múltiplos atendentes ou atendimento concorrente;
- uso de bibliotecas externas ou frameworks;
- persistência de dados entre recarregamentos da página.

## Restrições técnicas

- Aplicação web de página única.
- Implementação em HTML, CSS e JavaScript sem bibliotecas externas.
- Dados mantidos somente em memória durante a sessão do navegador.
- Sem autenticação, banco de dados, prioridade de senha ou atendimento concorrente.
